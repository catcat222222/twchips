# taifex-daily

抓台灣期交所每日行情的 Python 小工具。不用註冊、不用 token，直接跟期交所官網要資料，回來就是 pandas DataFrame。

會做這個是因為我自己的盤後流程每天要用期交所的結算價跟未平倉數字，找了一圈：能用的爬蟲大多停更很久，活著的數據服務又要註冊拿 token。這段程式每個做台灣期權的人大概都自己重寫過一遍，乾脆抽出來變成套件。

## 安裝

還沒上 PyPI，先用 git 裝：

```
pip install git+https://github.com/catcat222222/taifex-daily
```

## 用法

```python
import taifex_daily as td

# 台指期某天的日行情（開高低收、結算價、未沖銷契約數）
fut = td.futures_daily("2026-07-31", session="regular")

# 台指選擇權整條鏈，自己往下篩
opt = td.options_daily("2026-07-31", session="regular")
aug_puts = opt[(opt["買賣權"] == "賣權") & (opt["到期月份(週別)"] == "202608")]
```

商品代號照期交所的來：`TX`、`MTX`、`TE`、`TF`、`TXO`⋯⋯。`session` 給 `"regular"`（一般時段）、`"after_hours"`（盤後），不給就是全部。

欄位名稱保留期交所的原文中文，值有清過——千分位逗號、`-`、百分比符號都處理掉了，數字欄是真的數字。非交易日會拿到空的 DataFrame，不會報錯。

## 已知限制

- 一次只能抓一天。要抓一段歷史請自己迴圈，中間記得 sleep——資料是期交所免費提供的，別把人家打掛。
- 只有日行情。每筆成交（tick）、三大法人、最後結算價都還沒做，做到我自己需要的時候會加。
- 期交所哪天改版面這個就會壞。測試用的是真實回應的存檔，發現壞了開 issue 跟我說。
